# NayJi7 Homebrew tap

Homebrew formulas for [NayJi7](https://github.com/NayJi7)'s tools.

## gitoui

[gitoui](https://github.com/NayJi7/gitoui) is a terminal Git client with an image-rendered commit graph and a built-in GitHub pull request and issue client.

```sh
brew install nayji7/tap/gitoui
```

Works on macOS (Apple Silicon and Intel) and Linux (x86_64 and arm64). The formula installs the prebuilt binaries from the [GitHub releases](https://github.com/NayJi7/gitoui/releases).
